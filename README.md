# FluxoHub

FluxoHub is a private project hub designed to help developers organize, present, and test their projects in one place.

The main idea is simple: not every project is deployed, finished, or ready for production, but it can still be valuable. FluxoHub makes it possible to showcase projects through descriptions, repository links, preview links, and temporary demo sessions.

This project is currently in development.

## What is FluxoHub?

FluxoHub is a portfolio-style platform where projects can be registered, documented, and prepared for demonstration.

A project may have:

- A GitHub or GitLab repository
- A preview link, when available
- A short description
- A development status
- Demo instructions
- A temporary local container-based preview

The goal is to make projects easier to present, even when they are still running locally or are not deployed online.

## Main idea

FluxoHub allows a project to be shown in different ways:

- As a simple project page
- Through an external preview link
- Through a repository link
- Through a temporary demo started from a local environment

For the first version, the focus is on running personal projects locally and exposing them safely for testing and presentation.

## Why this project exists

Many developers have useful projects that are not online yet.

Some are still in development.  
Some only run locally.  
Some are private experiments.  
Some are learning projects.  

FluxoHub was created to help organize and present these projects without requiring every one of them to be permanently deployed.

## Planned features

- Project registration
- Project status tracking
- GitHub/GitLab repository reference
- External preview link support
- Local project validation
- Temporary demo sessions
- Container-based project execution
- Public or private project pages
- Simple portfolio view

## Development status

FluxoHub is currently under active development.

The first version will focus on personal use, local execution, and controlled project demos. Future versions may evolve into a more complete SaaS platform.

## Tech stack

FluxoHub will be built with:

- Angular
- Node.js
- PostgreSQL

## Project vision

FluxoHub aims to become a place where developers can show what they are building, even before it is fully launched.

The long-term vision is to support project discovery, temporary previews, repository-based demos, and a better way to present work in progress.
